BCS515B

Artificial Intelligence

Important Questions

Module 1

Repeated 4 Times

  • Q1. Explain PEAS description for different intelligent-agent tasks such as biometric authentication, automated taxi driving, playing tennis/high jump/auction bidding, robot soccer, internet book-shopping and autonomous Mars rover.

Repeated 3 Times

  • Q1. Define Artificial Intelligence and explain its foundations, categories or basic concepts.
  • Q2. Characterize and compare task environments such as deterministic and stochastic, static and dynamic, episodic and sequential, and fully observable and partially observable.

Repeated 2 Times

  • Q1. Define an agent and explain agent-related concepts such as the agent function and agent program.
  • Q2. Explain the interaction of an agent with its environment through sensors and actuators.
  • Q3. List the types of agents and explain goal-based and utility-based agents with neat diagrams.

Appeared Once

  • Q1. Explain Alan Turing's significant contribution to Artificial Intelligence and give a brief introduction to the Turing Test.
  • Q2. Discuss whether Artificial Intelligence is a science, engineering, or both.
  • Q3. Explain AI literature tasks that have been solved by computers, including playing table tennis, discovering mathematical theorems, providing competent legal advice and composing a symphony.

Module 2

Repeated 5 Times

  • Q1. Explain problem formulation and the components of a well-defined problem. Formulate a suitable problem for a given problem-solving task.
  • Q2. Explain Breadth-First Search (BFS) and its properties, benefits, evaluation criteria or application as a problem-solving strategy.

Repeated 3 Times

  • Q1. Compare or explain Depth-Limited Search (DLS) and Iterative Deepening Depth-First Search (IDDFS).

Repeated 2 Times

  • Q1. Explain the performance criteria used to measure search strategies, including completeness, time complexity, space complexity and optimality.
  • Q2. Explain problem-solving agents along with their algorithm and assumptions.

Appeared Once

  • Q1. Explain the tree-search and graph-search algorithms.
  • Q2. Illustrate the incremental formulation of the 8-Queens problem.
  • Q3. Explain state space, search node, transition model and branching factor.
  • Q4. Explain the reachability problem in the 8-puzzle.
  • Q5. Prove or give a counterexample showing whether BFS is a special case of Uniform-Cost Search (UCS), and whether UCS is a special case of A*.

Module 3

Repeated 7 Times

  • Q1. Explain and apply the A* search algorithm for shortest-path or heuristic search problems, showing heuristic values, edge costs and search steps where applicable.

Repeated 3 Times

  • Q1. Define a knowledge-based agent and explain or outline the knowledge-based agent program.
  • Q2. Explain the Universal Instantiation and Existential Instantiation techniques.

Repeated 2 Times

  • Q1. Explain A* heuristic properties such as admissibility and consistency, including suitable examples or counterexamples.
  • Q2. Explain Propositional Logic, including its syntax and semantics.
  • Q3. Explain the characteristics of Wumpus World and construct a simple propositional knowledge base for reasoning in Wumpus World.

Appeared Once

  • Q1. Explain Greedy Best-First Search and apply it along with A* search to a given graph.
  • Q2. Apply heuristic search to the given 8-puzzle problem to reach the goal state from the initial state.

Module 4

Repeated 3 Times

  • Q1. Explain First-Order Logic syntax, including its representation in BNF form.
  • Q2. Explain Universal and Existential Quantifiers and differentiate between them with suitable examples.
  • Q3. Explain Universal Instantiation and Existential Instantiation.

Repeated 2 Times

  • Q1. Explain the knowledge-engineering process for representing knowledge in First-Order Logic.
  • Q2. Illustrate the unification algorithm used for reasoning, with an example.
  • Q3. Illustrate the Kinship domain with an example.

Appeared Once

  • Q1. Explain the drawbacks of Propositional Logic and the syntax and semantics of First-Order Logic.
  • Q2. Explain FOL terms, atomic sentences, nested quantifiers and equality with suitable examples.
  • Q3. Explain valid and necessary true First-Order Logic sentences.
  • Q4. Explain Generalized Modus Ponens and its representations.
  • Q5. Use models to show the entailment of a universally quantified statement from a knowledge base.
  • Q6. Represent an arbitrary-size 3-SAT problem using a single First-Order Logic definite clause and ground facts.

Module 5

Repeated 4 Times

  • Q1. Explain the Backward Chaining algorithm for definite clauses and construct a proof tree for a given example.

Repeated 3 Times

  • Q1. Explain how a planning graph can be used to obtain a better heuristic for a planning problem.

Repeated 2 Times

  • Q1. Explain Classical Planning and solve a Blocks World problem for a given start state and goal state.
  • Q2. Apply Resolution to prove a given statement such as "West is a criminal."

Appeared Once

  • Q1. Explain planning as a state-space search problem.
  • Q2. Explain the differences and similarities between problem solving and planning.
  • Q3. Prove the completeness of backward search with PDDL.
  • Q4. Explain how dropping negative effects results in relaxed planning.
  • Q5. Explain Prolog predicates, proof trees and standard list operations.
  • Q6. Convert given First-Order Logic statements into Conjunctive Normal Form (CNF).
  • Q7. Explain the two approaches to searching for a plan.
  • Q8. Explain planning-graph counterexamples and related reasoning.
  • Q9. Apply Resolution for examples such as "curiosity killed the cat."
