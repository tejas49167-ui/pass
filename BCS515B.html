BCS515B

Artificial Intelligence

Important Questions

MODULE 1

Repeated 4 Times

  • Q1. Explain Artificial Intelligence and its foundations / four approaches of Artificial Intelligence.
  • Q2. Give a PEAS description for the given task or agent, such as an automated taxi driver, biometric authentication system, Wumpus World, tennis match, high jump or auction bidding.

Repeated 2 Times

  • Q3. Explain the properties of task environments.
  • Q4. Explain goal-based, utility-based, learning-based and simple reflex agents.

Appeared Once

  • Q5. Define Intelligence, Artificial Intelligence, Agent, Rationality and Logical Reasoning with examples.
  • Q6. Explain whether Artificial Intelligence is a science, engineering or both.
  • Q7. Explain various application domains of Artificial Intelligence.
  • Q8. Explain how agents interact with task environments with a suitable block diagram.
  • Q9. Explain the simple reflex agent for the vacuum environment.

MODULE 2

Repeated 3 Times

  • Q1. Explain problem formulation and formally define a search problem using a suitable example such as the Vacuum World.

Repeated 2 Times

  • Q2. Illustrate Breadth-First Search and Depth-First Search with a suitable example.
  • Q3. Apply the Greedy Best-First Search algorithm to a given graph and show the various stages in computing the solution.
  • Q4. Apply the A* Search algorithm to a given graph with heuristic values and show all steps in computing the solution.
  • Q5. Explain Depth-Limited Search and Iterative Deepening Depth-First Search.
  • Q6. Explain the state-space representation for the Vacuum World / 8-puzzle problem.

Appeared Once

  • Q7. List and define the four phases of the problem-solving process.
  • Q8. Explain the five components of a well-defined problem with an 8-puzzle example.
  • Q9. Explain the different metrics used to evaluate an algorithm's performance.
  • Q10. List and explain the three kinds of queues used in Best-First Search.
  • Q11. Define State Space, Search Node, Transition Model and Branching Factor with examples.
  • Q12. Compare Breadth-First Search, Uniform-Cost Search and A* Search, and prove the required relationships.

MODULE 3

Repeated 2 Times

  • Q1. Explain Knowledge-Based Agents and the TELL and ASK functions with an algorithm.
  • Q2. Represent the Wumpus World problem using PEAS and explain its characteristics and knowledge-based representation.
  • Q3. Explain different methods of deriving or obtaining heuristics.

Appeared Once

  • Q4. Explain the syntax and semantics of Propositional Logic.
  • Q5. Determine whether a given heuristic is admissible and consistent, and construct an admissible heuristic that is not consistent.
  • Q6. Prove that a consistent heuristic must be admissible.
  • Q7. Determine the number of models for given propositional sentences.
  • Q8. Determine whether given propositional statements are valid, satisfiable or unsatisfiable.

MODULE 4

Repeated 3 Times

  • Q1. Explain the syntax and semantics of First-Order Logic.

Repeated 2 Times

  • Q2. Explain the Knowledge Engineering Process and its various steps.
  • Q3. Explain Universal Instantiation and Existential Instantiation with suitable examples.

Appeared Once

  • Q4. Write logical representations for given sentences using generalized modus ponens.
  • Q5. Explain Assertions and Queries in First-Order Logic.
  • Q6. Explain Unification algorithm with a suitable example.
  • Q7. Explain how to write a 3-SAT problem of arbitrary size using a single First-Order Definite Clause and a limited number of ground facts.
  • Q8. Determine whether a First-Order Logic sentence is entailed by a given knowledge base using models.

MODULE 5

Repeated 3 Times

  • Q1. Explain the Backward Chaining algorithm with an example.

Repeated 2 Times

  • Q2. Explain the Forward Chaining algorithm with an example.
  • Q3. Explain classical planning and the Blocks World problem.
  • Q4. Explain the two approaches to searching for a plan.

Appeared Once

  • Q5. Illustrate the procedure for converting a First-Order Logic sentence into Conjunctive Normal Form (CNF).
  • Q6. Explain the differences and similarities between problem solving and planning.
  • Q7. Explain PDDL and its use in planning problems.
  • Q8. Explain Planning Graphs and prove the given assertions about planning graphs.
  • Q9. Explain categories and objects with suitable examples.
  • Q10. Explain events, time, fluents and objects in planning.
  • Q11. Explain the given Prolog predicate, and show proof trees and solutions for the given queries.
