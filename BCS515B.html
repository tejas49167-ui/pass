BCS515B

Artificial Intelligence

Important Questions

Module 1

Repeated 4 Times

  • Q1. Specify the PEAS description for a given intelligent agent or task environment.

Repeated 3 Times

  • Q2. Define Artificial Intelligence and explain its foundations, categories or nature.

Repeated 2 Times

  • Q3. Explain the characteristics of task environments, including fully/partially observable, single/multi-agent, deterministic/stochastic and static/dynamic environments.

Appeared Once

  • Q4. Explain how agents interact with their environments through sensors and actuators.
  • Q5. Define Intelligence, Artificial Intelligence, Agent, Rationality and Logical Reasoning.
  • Q6. Explain whether Artificial Intelligence is a science, engineering, or both.
  • Q7. Write pseudocode for goal-based and utility-based agent programs.

Module 2

Repeated 3 Times

  • Q1. Explain the components of a well-defined problem and formulate a problem using examples such as Vacuum World or the 8-puzzle.
  • Q2. Explain Breadth-First Search (BFS) and its evaluation criteria.
  • Q3. Explain Depth-Limited Search (DLS) and Iterative Deepening Depth-First Search (IDDFS).

Repeated 2 Times

  • Q4. Compare uninformed search strategies such as BFS, UCS, DFS and DLS with respect to completeness, time complexity, space complexity and optimality.

Appeared Once

  • Q5. Explain a simple problem-solving agent with its algorithm and assumptions.
  • Q6. Explain the state space for Vacuum World with suitable representation.
  • Q7. Define State Space, Search Node, Transition Model and Branching Factor with suitable examples.
  • Q8. Explain the formulation of the 8-puzzle problem.
  • Q9. Prove or disprove that BFS is a special case of Uniform-Cost Search.
  • Q10. Prove or disprove that Uniform-Cost Search is a special case of A* Search.
  • Q11. Explain the reachability of states in the 8-puzzle and how to determine whether a state is reachable.

Module 3

Repeated 5 Times

  • Q1. Apply A* Search to a given graph/problem, showing the stages of search and determining the solution path.

Repeated 2 Times

  • Q2. Explain Knowledge-Based Agents with the algorithm and the TELL and ASK functions.
  • Q3. Explain Wumpus World characteristics and construct/use a simple propositional knowledge base to prove the location of the Wumpus.

Appeared Once

  • Q4. Apply Greedy Best-First Search to a given graph.
  • Q5. Compare Greedy Best-First Search and A* Search.
  • Q6. Explain heuristic functions and their role in informed search.
  • Q7. Explain admissible and consistent heuristics with suitable examples.
  • Q8. Prove that a consistent heuristic must be admissible and construct an admissible but inconsistent heuristic.
  • Q9. Explain propositional logic, including its syntax, semantics, models and reasoning.
  • Q10. Determine whether given propositional sentences are valid, satisfiable or unsatisfiable.
  • Q11. Determine the number of models satisfying given propositional sentences.

Module 4

Repeated 3 Times

  • Q1. Explain Universal Instantiation and Existential Instantiation with suitable examples.

Repeated 2 Times

  • Q2. Explain the syntax and semantics of First-Order Logic (FOL).
  • Q3. Explain the Knowledge Engineering Process and its steps in First-Order Logic.

Appeared Once

  • Q4. Explain the drawbacks of propositional logic and the need for First-Order Logic.
  • Q5. Explain FOL terms, atomic sentences, universal quantifiers, existential quantifiers, nested quantifiers and equality with suitable examples.
  • Q6. Explain Assertions and Queries in First-Order Logic.
  • Q7. Explain the kinship domain using First-Order Logic.
  • Q8. Explain the representation of numbers, sets and lists in First-Order Logic.
  • Q9. Explain logical representations using Generalized Modus Ponens with suitable examples.
  • Q10. Explain the Unification Algorithm with suitable examples.
  • Q11. Explain FOL entailment using models.
  • Q12. Explain the difference between propositional inference and First-Order inference.
  • Q13. Represent a 3-SAT problem using a single First-Order Logic definite clause and suitable ground facts.

Module 5

Repeated 3 Times

  • Q1. Explain the Backward Chaining algorithm with a suitable example.
  • Q2. Explain Classical Planning with the Blocks World example.

Repeated 2 Times

  • Q3. Explain Planning Graphs and their use for heuristic estimation.

Appeared Once

  • Q4. Explain planning as a state-space search problem.
  • Q5. Explain the two approaches to searching for a plan.
  • Q6. Explain Forward Chaining and compare it with Backward Chaining.
  • Q7. Explain how First-Order Logic sentences are converted into Conjunctive Normal Form (CNF).
  • Q8. Explain Resolution in First-Order Logic with its procedure.
  • Q9. Explain PDDL and its role in planning problems.
  • Q10. Explain the differences and similarities between problem solving and planning.
  • Q11. Prove that backward search with PDDL problems is complete.
  • Q12. Explain why dropping negative effects from action schemas produces relaxed planning problems.
  • Q13. Explain the Graphplan algorithm.
  • Q14. Write Prolog predicates and construct proof trees for suitable queries.
