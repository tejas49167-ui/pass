BCS503

Theory of computation

Important Questions

MODULE 1

Repeated 4 Times

  • Q1. Design DFA for the given language with suitable transition diagram.
  • Q2. Convert an NFA to its equivalent DFA.

Repeated 3 Times

  • Q3. Define Alphabet, String and Language with suitable examples.
  • Q4. Find the ε-closure of states and convert an ε-NFA to DFA.

Repeated 2 Times

  • Q5. Design DFA to accept binary numbers divisible by 5.

Appeared Once

  • Q6. Define Deterministic Finite Automata (DFA) and the language accepted by it.
  • Q7. Define Non-deterministic Finite Automata (NFA).
  • Q8. Define reverse of a string and concatenation of languages with examples.
  • Q9. Design an NFA to recognize a given finite set of strings.

MODULE 2

Repeated 4 Times

  • Q1. Define Regular Expression and write Regular Expressions for the given languages.
  • Q2. State and prove the Pumping Lemma for Regular Languages and use it to prove that a given language is not regular.
  • Q3. Obtain an ε-NFA / NFA for a given Regular Expression.

Repeated 3 Times

  • Q4. Minimize a DFA using the Table Filling Algorithm.
  • Q5. Prove that Regular Languages are closed under Union, Concatenation, Kleene Star, Intersection, Complementation and Difference.

Repeated 2 Times

  • Q6. Obtain the Regular Expression corresponding to a given finite automaton using the state elimination method or Kleene's theorem.

Appeared Once

  • Q7. Explain the applications of Regular Expressions.

MODULE 3

Repeated 4 Times

  • Q1. Construct a Context-Free Grammar (CFG) for the given languages.
  • Q2. Obtain the Leftmost Derivation (LMD), Rightmost Derivation (RMD) and Parse Tree for a given string. Determine whether the grammar is ambiguous.
  • Q3. Design a Pushdown Automaton (PDA) for a given language and show the moves or instantaneous descriptions for the given string.

Repeated 3 Times

  • Q4. Define Context-Free Grammar, Leftmost Derivation, Rightmost Derivation, Parse Tree and Ambiguous Grammar with examples.

Repeated 2 Times

  • Q5. Convert a given CFG to PDA.

Appeared Once

  • Q6. Discuss the language accepted by PDA.
  • Q7. Obtain an unambiguous grammar for a given grammar and derive the specified expression.

MODULE 4

Repeated 4 Times

  • Q1. Define Chomsky Normal Form (CNF) and convert the given CFG to CNF.
  • Q2. Prove the closure properties of Context-Free Languages under the specified operations.

Repeated 2 Times

  • Q3. State and prove the Pumping Lemma for Context-Free Languages and show that a given language is not context-free.
  • Q4. Define Greibach Normal Form (GNF) and convert the given CFG to GNF.
  • Q5. Eliminate ε-productions, unit productions and useless symbols from the given grammar.

Appeared Once

  • Q6. Eliminate left recursion from the given grammar.

MODULE 5

Repeated 4 Times

  • Q1. Define a Turing Machine and explain the working of a basic Turing Machine with a neat diagram.

Repeated 3 Times

  • Q2. Design a Turing Machine to accept the language L = {aⁿbⁿcⁿ | n ≥ 1} and show the moves for the given string.
  • Q3. Explain the variants of Turing Machines, including Multi-Tape Turing Machines.

Repeated 2 Times

  • Q4. Explain the programming techniques for Turing Machines.

Appeared Once

  • Q5. Explain the Church-Turing Machine with a neat diagram.
  • Q6. Design a Turing Machine to accept the language L = {0ⁿ1ⁿ | n ≥ 0} and show that the string 0011 is accepted.
  • Q7. Design a Turing Machine to accept the language L = {1ⁿ2ⁿ3ⁿ | n ≥ 1} and show that the string 111222333 is accepted.
  • Q8. Design a Turing Machine to accept a palindrome over {a, b} and draw the transition diagram.
  • Q9. Explain language acceptability and the design of Turing Machines.
  • Q10. Explain the model of Linear Bounded Automata (LBA) with a neat diagram.
  • Q11. Explain Recursively Enumerable Languages.
  • Q12. Explain the Undecidability Problem.
  • Q13. Explain Non-Deterministic Turing Machine.
